# Headless telemetry

Test-only script modules that `tools/Test-Headless.ps1` copies into a throwaway
mod, `BOI Headless Telemetry`, inside each run folder. They never ship.

| Module | Loaded when | Logs (`BOITM|<group>|…`) |
|---|---|---|
| `core/` | always, including `-Control` | `country` (GDP, SoL, population, states), `infrastructure` (total, usage, deficit states), `goods` for transportation, merchant marine, grain and tools |
| `boi/` | a loaded mod defines `horses` | `works` (Rail Works and railway levels, Road Works levels per tier, goods at base price, expenses), `politics` (radicals, loyalists, turmoil, war), `goods` for automobiles, oil, electricity, coal, wood, services, iron, steel and glass, `boi` (ranch, Road Works and Harbour Works levels; states where horses are ≥50% pricier or ≥25% cheaper), `budget` (gold reserves), `debt` (scaled debt, states with Public Works) and `goods` for horses. Also one `BOIDIAG|<date>|<tag>|<state>|…` line per state that has Public Works or Harbour Works, or is under 5 spare infrastructure (levels, queued, occupancy band, spare, AI score). Read those with `tools\Get-BoiDiagnostics.ps1 -Run <run>`. |
| `boi_states/` | with `boi/`, unless `-LongRun` | Every country, yearly and keyed by engine id: `BOICT|<kind>|<date>|<tag>|<id>|…` (states, war, radicals, loyalists, turmoil, market, income, expenses, gold, debt, GDP) and `BOIST|<kind>|<date>|<tag>|<id>|<state>|…` per state (isolated, market access, port, railway, Public Works and Harbour Works levels; unrest, unemployment, wage, GDP; transportation demand, supply and price). Isolated states read exactly 0 market access. **These yearly lines go with a repeatable game crash; the cause isn't found (see the lessons file).** Read these with `tools/Get-StateDiagnostics.py <run> [--tag GBR] [--year 1845]` |
| `probes/` | `-Probes` | Not metrics: the 2026-11-03 engine probes, run as France, logging `BOIPROBE|` lines |
| `housing/` | a loaded mod defines `boi_housing` | `housing` and `housing_tiers` (levels per building type), `light_heat` (levels per fuel), `BOIPOL|` pollution per state for major powers, `company_housing` (levels on each tier), `housing_prices` (state price bands), and `goods` for both housing goods. Also, yearly for every country, `BOIHS|<kind>|<date>|<tag>|<state>|…` lines per state: population, urbanization, buildings, infrastructure, SoL, housing and luxury demand, supply and price, Horse Ranch levels with horse demand, supply and price, and `works` (Road, Rail, Harbour and railway levels). `tools/Get-HousingSeedDemand.py` and `tools/Get-HorseMarkets.py` read these. Also `BOILAW|<date>|<tag>|…` once a year per country: employer housing, residential standards and road financing law, plus interest groups and how many hold a housing stance. `tools/Get-CenturyDetail.py` reads these |
| `ensemble/` | `-Ensemble` (both arms) | Not `BOITM|`. Each quarter, every country except decentralized ones, every state and every market logs `BOIENS|<group>|<date>|…` lines on one shared day: about 70 country metrics, 21 state metrics, and the price, buy and sell orders of all 52 vanilla goods. About 1 MB of log per snapshot. Driven by `tools/Invoke-HeadlessEnsemble.ps1` and read by `tools/ensembles/Build-EnsembleDb.py`; see `tools/ensembles/README.md`. The event file is generated by `tools/ensembles/Generate-EnsembleEvents.py`; don't edit it by hand |
| `fixtures/` | with `housing/`, unless `-NoFixtures` | Not metrics: runs BOI's console-only housing debug events (`boi_housing.2` to `.4`) as Portugal from 1836-02 and logs `BOIFIX|<date>|<check>|<pass/fail/warn/info>|<detail>` lines. `Test-Headless.ps1` tabulates them in `summary.md` and fails the run on any `fail`. The chain takes about 100 in-game days. It changes Portugal's buildings and laws, so Portugal's own telemetry is not comparable with a control run |

Each major power (`country_rank >= rank_value:major_power`) logs one line per
group on its `on_yearly_pulse_country`. The pulse is staggered per country.
Values are script values printed with `[THIS.ScriptValue('…')|2]`, which come
out as raw numbers. Keep one metric group per `debug_log`, because a data
function that fails blanks its whole line. The harness fails a run that has
blank values or errors mentioning `boitm`.

To add a metric:
1. Add a script value to the module's `common/script_values/` file.
2. Add `key=[THIS.ScriptValue('…')|2]` to a line in its `events/` file.
3. Add the key to `-Metrics` in `tools/Get-HeadlessReport.ps1` if it should show
   in the report.

Housing is part of BOI (merged 2026-10-30), so the housing module loads in every
BOI run. It is selected by the `boi_housing` good wherever it is defined.

Report: `tools\Get-HeadlessReport.ps1 -Run <mod run> -Compare <control run>`. For a table against the vanilla baseline: `python tools/Get-BalanceSummary.py <run>`. For long runs, `python tools/Get-CenturyDetail.py <run> [more runs]` adds state losses, stalled works orders, Municipal Estates losses, and the laws and PMs in the last autosave.
