# ================================================================
#  Burden of Infrastructure — Public Works hub production methods
#
#  Plan 12 (docs/plans/12_PUBLIC_WORKS_HUB_IMPLEMENTATION.md), built
#  2026-11-13. All numbers are first-pass test values.
#
#  One hub per state, sized by script: each level maintains up to
#  BOI_PW_CAP (20) points of chargeable infrastructure use (use above
#  the population floor). Inputs below are PER LEVEL at full use; a
#  monthly script trims them to the actual use with a building
#  modifier (boi_pw_goods_trim), so consumption follows use.
#  Inputs x1.5 for game 3 (2026-11-13): the bill was ~1.5% of national
#  spending in games 1-2, lighter than vanilla's railway subsidies.
#
#  The PMs carry no state modifiers on purpose. The hub's benefit is
#  cancelling the decay penalty, and a PM modifier would scale with
#  the level count. The monthly script applies the cancellation
#  (boi_network_upkeep) from occupancy and goods shortage, and adds the
#  Mode and Harbour bonuses listed here as comments.
#
#  AI choice: default ai_selection (most_profitable). A building that
#  sells nothing moves to the CHEAPEST PM at local prices (verified
#  1.15.1, lessons file), so a state with dear transportation and
#  cheap horses keeps a horse mode longer.
#
#  Laborer counts stay at or above 125: the Turnpike Trusts financing
#  PM removes 45 laborers per level.
# ================================================================
