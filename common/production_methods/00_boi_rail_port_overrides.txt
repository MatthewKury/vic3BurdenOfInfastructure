# ================================================================
#  Burden of Infrastructure — Railway & Port PM shadows
#
#  EARLY-LOAD OVERRIDE FILE. The production method database is
#  first-read-wins in ASCII filename order, so "00_boi_" sorts
#  before vanilla's "11_private_infrastructure.txt" and these
#  copies win. Vanilla logs one harmless line per key:
#      "Duplicated key pm_X will not be created from file:
#       common/production_methods/11_private_infrastructure.txt"
#  That is EXPECTED. Only the duplicated keys are discarded - the
#  rest of the vanilla file still loads normally.
#
#  WHAT CHANGED: every "state_infrastructure_add" line has been
#  removed. That is the whole point of the mod - infrastructure is
#  no longer a free by-product of railways and ports, it comes from
#  building_boi_infrastructure and building_boi_harbour_works.
#
#  WHAT DELIBERATELY DID NOT CHANGE:
#   - goods_output_transportation_add / _merchant_marine_add stay.
#     Mines, plantations, logging camps, fishing wharves and oil
#     rigs all consume transportation in their automation PMs, and
#     the Infrastructure building's own later PMs consume it too.
#     Removing it would break vanilla.
#   - state_pollution_generation_add stays. Several of these
#     state_modifiers blocks carry pollution alongside the
#     infrastructure line; only the infrastructure line goes.
#   - required_input_goods on the electric trains stays (it sits
#     AFTER the state_modifiers block in vanilla - easy to lose).
#
#  PATCH SENSITIVITY: each block below is a full copy of vanilla
#  1.13 with one line removed, tagged "# BOI:". After every game
#  update, re-diff against vanilla 11_private_infrastructure.txt
#  and re-apply upstream changes.
#
#  NOT shadowed: pm_anchorage (has no state_infrastructure_add),
#  and the passenger-carriage PMs (transportation output only).
# ================================================================
