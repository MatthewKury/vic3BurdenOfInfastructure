# ================================================================
#  Burden of Infrastructure — horse lines on vanilla production methods
#
#  Replaces the four 00_boi_* full-copy shadows (transport, farm,
#  subsistence and urban transport overrides) since 2026-11-13 (plan 10).
#  Each INJECT appends one building_modifiers block holding only BOI's
#  line. Verified on 1.15.1: an injected block applies alongside the
#  vanilla one (VIC3_MODDING_LESSONS.md section 1). Nothing vanilla is
#  copied, so a patch that changes these PMs needs no re-diff here.
#
#  Haulage ladder on mines, plantations, vineyards, logging camps and oil rigs:
#      pm_road_carts            (no tech, empty in vanilla)  horses 3
#        -> pm_rail_transport_* (railways)                   horses 1, last-mile cartage
#        -> pm_log_carts etc.   (electric_railway)           untouched
#  pm_log_carts is NOT a horse cart: it is the most advanced logging tier.
#  Cold-chain PMs (refrigeration, flash freezing) are not haulage and are untouched.
# ================================================================

# ── Haulage (vanilla 03_mines, 04_plantations, 09_misc_resource) ──
# pm_road_carts reaches 18 PM groups: every mine, plantation, vineyard,
# logging camp and oil rig starts on it. The mod's main pre-rail pressure.
INJECT:pm_road_carts = {
	building_modifiers = { workforce_scaled = { goods_input_horses_add = 3 } } # 90
}

	building_modifiers = { workforce_scaled = { goods_input_horses_add = 1 } } # last-mile cartage
}

}
INJECT:pm_rail_transport_building_logging_camp = {

}
