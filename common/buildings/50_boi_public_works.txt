# ================================================================
#  Burden of Infrastructure — Public Works hub (plan 12, 2026-11-13)
#
#  One per state, modelled on vanilla's army and navy logistics
#  centres: never built by hand, sized by BOI's monthly script
#  (events/boi_public_works_events.txt) to the state's chargeable
#  infrastructure use, and seeded staffed in 1836 history
#  (common/history/buildings/zz_boi_public_works_seed_generated.txt).
#
#  The coastal version adds a Harbour PM group. Its potential is
#  is_coastal; the inland version has none, so a coastal state seeded
#  without a port still has a valid hub.
#
#  Government-funded group, so ownership_type must be no_ownership.
# ================================================================
