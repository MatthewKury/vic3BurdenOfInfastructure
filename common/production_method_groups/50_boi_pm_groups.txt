# ================================================================
#  Burden of Infrastructure — Production Method Groups
#
#  Public-service groups use most_productive. Horse Ranches use
#  most_profitable because they sell a good and face input prices.
#
#  The default is most_profitable, which is meaningless on a
#  building with no salable output: the Infrastructure and Harbour
#  Works buildings emit a state modifier rather than a good, so
#  they have no revenue for the AI to compare. Vanilla sets
#  most_productive on all three Government Administration groups
#  for exactly this reason. Without it, AI countries would pick
#  their infrastructure methods essentially at random.
# ================================================================
