# ================================================================
#  Burden of Infrastructure — top-bar alerts
#
#  One alert of its own for each repeatable BOI decision, so the player
#  sees when it comes back off cooldown instead of finding it inside
#  vanilla's grouped can_take_decisions entry. type = alert puts each on
#  the top bar with its own icon (not inside the important-actions
#  group). Clicking opens the journal, where decisions are taken.
#
#  The valid triggers repeat each decision's is_shown + possible; they
#  live next to the decision's other triggers. Format: the header of
#  vanilla common/alert_types/00_alert_types.txt. Added 2026-11-15.
# ================================================================
